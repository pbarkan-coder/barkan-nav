# Barkan Nav

אפליקציית אנדרואיד לנסיעה משולבת בישראל: ברכב עד חניון "חנה וסע", ומשם בתחבורה ציבורית.

## איך משתמשים

1. **יעד:** כותבים לאן נוסעים. יעדים קודמים מופיעים ככפתורים מתחת לשדה.
2. **חניון:**
   - מובנים באפליקציה חנה וסע שפיים וחנה וסע ראשון לציון.
   - "בחר את החניון הקרוב אליי" בוחר ביניהם לפי מיקום משוער.
   - אפשר להוסיף חניון בהקלדה, או לשתף מקום מגוגל מפות ל-Barkan Nav.
3. **יוצאים לדרך:**
   - שלב א: ניווט ברכב לחניון, ב-Waze או בגוגל מפות.
   - שלב ב: מסלול בתחבורה ציבורית מהחניון ליעד, בגוגל מפות.

## השוואת זמנים

"ישירות ברכב או דרך חנה וסע?" משווה, דרך Google Routes API, בין נסיעה ישירה ליעד לבין נסיעה דרך החניון שנבחר (או הקרוב, אם לא נבחר):
- נסיעה ברכב לחניון, לפי פקקים בזמן אמת;
- 5 דקות לחניה ולהליכה לתחנה;
- תחבורה ציבורית מהחניון ליעד, לפי לוח הזמנים (שכבר מגלם את הנתיב הציבורי);
- ולהשוואה, נסיעה ברכב עד היעד.

נדרש הסוד `MAPS_API_KEY` במאגר: מפתח Google Maps Platform עם Routes API בלבד, מוגבל לאפליקציית Android `com.peretz.barkannav` ול-SHA-1 של מפתח החתימה.

## פרטיות

- האינטרנט משמש לבדיקת גרסה חדשה ב-GitHub, ולחישוב זמנים ב-Google (נשלחים המיקום המשוער, היעד ושמות החניונים, רק כשלוחצים על ההשוואה). גרסה חדשה מותקנת רק אם היא חתומה באותו מפתח כמו הגרסה המותקנת.
- מיקום משוער נבדק רק כשלוחצים "בחר את החניון הקרוב אליי", ולא נשמר.
- היא רק פותחת את Waze ואת גוגל מפות עם המסלול.
- החניונים והיעדים נשמרים בטלפון בלבד, ולא מגובים לענן.

## בנייה

GitHub Actions בונה APK בכל דחיפה ל-`main` ומפרסם אותו ב-Releases.

לבנייה חתומה צריך במאגר את הסוד `KEYSTORE_PASSWORD`, ואת מפתח החתימה המוצפן `signing/release.p12`. את המפתח יוצרים פעם אחת עם ה-workflow "Create signing key", אחרי שמגדירים את הסוד.
בלי הסוד נבנית גרסת בדיקה בלבד, שמופיעה ב-Artifacts של הריצה.
